## Sources et suivi

La source à modifier est désormais le [texte maître](texte-maitre.md), en Markdown minimal, sans balises du site. Le [mode d’emploi](MODE-EMPLOI.md) explique comment produire localement le Word, le PDF, la copie en texte brut et les vues du site à partir de ce seul fichier. Double-cliquez sur **Generer-les-documents.cmd** pour créer les documents.

La présentation est définie séparément dans [le modèle du 9e Génie](modeles/9eg.json). Les fichiers sous `_includes/textes`, les références et l’avant-propos sont des vues générées; ne les modifiez pas directement. Les noms complets sont utilisés dans le document; les codes courts sont réservés aux onglets ou aux renvois à une disposition précise.

La séparation entre administration et finances conserve les dispositions, montants et conditions. Les anciens liens restent accessibles. Chaque paragraphe normatif est numéroté.
